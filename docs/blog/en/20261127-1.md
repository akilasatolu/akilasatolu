## I Built Tsuzuri: Write a README and Get a Docs Site

<small>Nov 27, 2026 · [All posts](index.md)</small>

### Why I built it

I could build services, but I couldn't spare time for their documentation. That was my problem.

So I wanted a service where writing just a README gives you something good enough to serve as a docs site. That is why I built [Tsuzuri](https://github.com/akilasatolu/tsuzuri).

### What it does

Starting from the README, it follows links to collect pages and publishes them as a GitHub Pages site. To add a page, you only add one link. Only files reachable through links go into the site.

- Sidebar, site search, in-page table of contents, and copy buttons on code
- Light and dark, with 10 styles to choose from in the gallery
- GitHub alerts, footnotes, and mermaid diagrams
- OGP images, sitemap.xml, llms.txt for AI tools, and multilingual sites

### How to use it

1. Run the following at the root of your repository (Node.js 20 or later). Press Enter at the two questions to use the defaults.

   ```sh
   npx github:akilasatolu/tsuzuri#v1 init
   ```

2. In GitHub, open **Settings → Pages** and set Source to **GitHub Actions** (first time only).
3. Commit the generated files and push to the default branch.

From then on, every push updates the site. The build runs on GitHub Actions.

### When it's not a fit

It is not a fit if you want to publish somewhere other than GitHub Pages, or keep separate documentation for each version.

The site is [here](https://akilasatolu.github.io/tsuzuri/).
