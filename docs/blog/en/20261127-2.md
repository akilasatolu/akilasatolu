## I Almost Lost the Point of Building It, Then Made tiny-md2docs, a One-Line Theme

<small>Nov 27, 2026 · [All posts](index.md)</small>

### I almost lost the point of building it

What Tsuzuri, from [the previous post](20261127-1.md), does can actually be done with GitHub Pages alone. Put Markdown there, and it can be published as a site as is. When I realized that, I almost lost the point of building it.

However, just publishing with Pages gives you only minimal styling. I felt that was not enough for a docs site.

So I made full use of the GitHub Pages and Jekyll ecosystem and built [tiny-md2docs](https://github.com/akilasatolu/tiny-md2docs) (tm2d), which lets you create a good enough docs site with just one line. It is a small Jekyll theme for GitHub Pages.

### How to use it

1. Write this one line in `docs/_config.yml`.

   ```yaml
   remote_theme: akilasatolu/tiny-md2docs
   ```

2. Put your Markdown files in `docs/`. The top page is `docs/index.md`.
3. In GitHub, open **Settings → Pages** and publish from the `/docs` folder of a branch.

"One line" refers to the configuration: you still need to add your Markdown and set up publishing in Pages. Also, with only this setting, the original `.md` files are published too. If you don't want that, you can change it in the [configuration](https://akilasatolu.github.io/tiny-md2docs/guide/config.html).

### Riding on how Jekyll works

It runs on the standard GitHub Pages build alone. No workflow, npm, or extra plugins are needed.

- `remote_theme` loads the theme
- Markdown without front matter also becomes a page
- If a folder has no `index.md`, `README.md` becomes the top page of that folder

### What it does

- Sidebar, previous and next links, breadcrumbs, and table of contents
- Search that handles Japanese (no external service)
- Dark mode, multilingual pages, code copy, and a 404 page
- UI parts such as buttons and badges, and printing
- CSS and JS are 16 KB or less in total, gzipped

### How it differs from Tsuzuri

Tsuzuri follows links from the README and builds with GitHub Actions. tm2d publishes the Markdown in `docs/` with the standard Pages build.

The site is [here](https://akilasatolu.github.io/tiny-md2docs/).
