## READMEを書けばドキュメントサイトになる「Tsuzuri」を作りました

<small>2026年11月27日 · [ブログ一覧](index.md)</small>

### 作った理由

サービスは作るのに、ドキュメントには時間を割けない。そんな悩みがありました。

そこで、READMEさえ書けば、ドキュメントサイトとして十分なものができるサービスにしたいと考えて作ったのが[Tsuzuri](https://github.com/akilasatolu/tsuzuri)です。

### できること

READMEを起点にリンクをたどってページを集め、GitHub Pagesのサイトとして公開します。ページを足したいときは、リンクを1つ足すだけです。サイトに入るのは、リンクでたどれるファイルだけです。

- サイドバー、サイト内検索、ページ内の目次、コードのコピーボタン
- ライトとダーク、ギャラリーから選べる10種類のスタイル
- GitHubのアラート、脚注、mermaidの図
- OGP画像、sitemap.xml、AI向けのllms.txt、多言語

### 使い方

1. リポジトリの直下で次を実行します(Node.js 20以上)。2つの質問は、Enterで進めれば既定値になります。

   ```sh
   npx github:akilasatolu/tsuzuri#v1 init
   ```

2. GitHubの **Settings → Pages** で、Sourceを **GitHub Actions** にします(最初の1回だけ)。
3. 生成されたファイルをcommitして、既定のブランチにpushします。

以後はpushするたびにサイトが更新されます。ビルドはGitHub Actionsで動きます。

### 向かないケース

GitHub Pages以外で公開したい場合や、版ごとに別のドキュメントを持ちたい場合には向きません。

サイトは[こちら](https://akilasatolu.github.io/tsuzuri/ja/)です。
