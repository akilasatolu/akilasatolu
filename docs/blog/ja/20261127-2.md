## 作る意味を失いかけて、1行で使えるテーマ「tiny-md2docs」を作りました

<small>2026年11月27日 · [ブログ一覧](index.md)</small>

### 作る意味を失いかけた

[前の記事](20261127-1.md)のTsuzuriと同じことは、実はGitHub Pagesだけでもできます。Markdownを置けば、そのままサイトとして公開できるからです。それに気づいて、作る意味を失いかけました。

ただ、Pagesでそのまま公開しただけでは、スタイルは最低限です。ドキュメントサイトとしては不十分だと感じました。

そこで、GitHub PagesとJekyllのエコシステムを存分に活用して、たった1行でドキュメントサイトとして十分なものが作れるようにしたのが[tiny-md2docs](https://github.com/akilasatolu/tiny-md2docs)(tm2d)です。GitHub Pagesで使う、小さなJekyllのテーマです。

### 使い方

1. `docs/_config.yml` に、次の1行を書きます。

   ```yaml
   remote_theme: akilasatolu/tiny-md2docs
   ```

2. `docs/` にMarkdownのファイルを置きます。トップページは `docs/index.md` です。
3. GitHubの **Settings → Pages** で、ブランチの `/docs` フォルダを公開元にします。

「1行」は設定の話で、Markdownを置くことと、Pagesの公開設定は必要です。また、この設定だけだと元の `.md` ファイルも公開されます。公開したくないときは、[設定](https://akilasatolu.github.io/tiny-md2docs/ja/guide/config.html)で変えられます。

### Jekyllの仕組みに乗る

GitHub Pagesの標準のビルドだけで動きます。ワークフローもnpmも、プラグインの追加も要りません。

- `remote_theme` で、テーマを読み込みます
- front matterがないMarkdownも、ページになります
- フォルダに `index.md` がなければ、`README.md` がそのフォルダのトップになります

### できること

- サイドバー、前後のリンク、パンくず、目次
- 日本語に対応した検索(外部のサービスは使いません)
- ダークモード、多言語、コードのコピー、404ページ
- ボタンやバッジなどのUIパーツ、印刷
- CSSとJSは、合わせてgzipで16KB以下

### Tsuzuriとの違い

TsuzuriはREADMEからリンクをたどり、GitHub Actionsでビルドします。tm2dは `docs/` のMarkdownを、Pagesの標準のビルドで公開します。

サイトは[こちら](https://akilasatolu.github.io/tiny-md2docs/ja/)です。
