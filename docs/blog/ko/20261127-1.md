## README를 쓰면 문서 사이트가 되는 「Tsuzuri」를 만들었습니다

<small>2026년 11월 27일 · [블로그 목록](index.md)</small>

### 만든 이유

서비스는 만드는데, 문서에는 시간을 내지 못한다. 그런 고민이 있었습니다.

그래서 README만 쓰면 문서 사이트로서 충분한 것이 만들어지는 서비스로 하고 싶다고 생각해 만든 것이 [Tsuzuri](https://github.com/akilasatolu/tsuzuri)입니다.

### 할 수 있는 것

README를 시작점으로 링크를 따라가며 페이지를 모아, GitHub Pages 사이트로 공개합니다. 페이지를 추가하고 싶을 때는 링크를 하나 추가하기만 하면 됩니다. 사이트에 들어가는 것은 링크로 따라갈 수 있는 파일뿐입니다.

- 사이드바, 사이트 내 검색, 페이지 내 목차, 코드 복사 버튼
- 라이트와 다크, 갤러리에서 고를 수 있는 10가지 스타일
- GitHub 알림 상자(alerts), 각주, mermaid 다이어그램
- OGP 이미지, sitemap.xml, AI용 llms.txt, 다국어

### 사용법

1. 저장소 루트에서 다음을 실행합니다(Node.js 20 이상). 두 가지 질문은 Enter로 넘어가면 기본값이 됩니다.

   ```sh
   npx github:akilasatolu/tsuzuri#v1 init
   ```

2. GitHub의 **Settings → Pages**에서 Source를 **GitHub Actions**로 설정합니다(처음 한 번만).
3. 생성된 파일을 commit하고, 기본 브랜치에 push합니다.

이후에는 push할 때마다 사이트가 갱신됩니다. 빌드는 GitHub Actions에서 실행됩니다.

### 맞지 않는 경우

GitHub Pages가 아닌 곳에 공개하고 싶거나, 버전마다 별도의 문서를 두고 싶은 경우에는 맞지 않습니다.

사이트는 [여기](https://akilasatolu.github.io/tsuzuri/)입니다.
