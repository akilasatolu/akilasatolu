## 만드는 의미를 잃을 뻔했다가, 한 줄로 쓰는 테마 「tiny-md2docs」를 만들었습니다

<small>2026년 11월 27일 · [블로그 목록](index.md)</small>

### 만드는 의미를 잃을 뻔했다

[이전 글](20261127-1.md)의 Tsuzuri와 같은 일은 사실 GitHub Pages만으로도 할 수 있습니다. Markdown을 두면 그대로 사이트로 공개할 수 있기 때문입니다. 그것을 깨닫고, 만드는 의미를 잃을 뻔했습니다.

다만 Pages로 그대로 공개하기만 해서는 스타일이 최소한입니다. 문서 사이트로서는 부족하다고 느꼈습니다.

그래서 GitHub Pages와 Jekyll의 생태계를 마음껏 활용해, 단 한 줄로 문서 사이트로서 충분한 것을 만들 수 있게 한 것이 [tiny-md2docs](https://github.com/akilasatolu/tiny-md2docs)(tm2d)입니다. GitHub Pages에서 쓰는 작은 Jekyll 테마입니다.

### 사용법

1. `docs/_config.yml`에 다음 한 줄을 씁니다.

   ```yaml
   remote_theme: akilasatolu/tiny-md2docs
   ```

2. `docs/`에 Markdown 파일을 둡니다. 첫 페이지는 `docs/index.md`입니다.
3. GitHub의 **Settings → Pages**에서 브랜치의 `/docs` 폴더를 공개 소스로 지정합니다.

"한 줄"은 설정에 대한 이야기이며, Markdown을 두는 것과 Pages의 공개 설정은 필요합니다. 또한 이 설정만으로는 원본 `.md` 파일도 공개됩니다. 공개하고 싶지 않을 때는 [설정](https://akilasatolu.github.io/tiny-md2docs/ko/guide/config.html)에서 바꿀 수 있습니다.

### Jekyll의 구조를 활용하기

GitHub Pages의 표준 빌드만으로 동작합니다. 워크플로도 npm도, 플러그인 추가도 필요 없습니다.

- `remote_theme`으로 테마를 불러옵니다
- front matter가 없는 Markdown도 페이지가 됩니다
- 폴더에 `index.md`가 없으면 `README.md`가 그 폴더의 첫 페이지가 됩니다

### 할 수 있는 것

- 사이드바, 이전·다음 링크, 브레드크럼, 목차
- 일본어를 지원하는 검색(외부 서비스는 쓰지 않습니다)
- 다크 모드, 다국어, 코드 복사, 404 페이지
- 버튼이나 배지 같은 UI 부품, 인쇄
- CSS와 JS는 합쳐서 gzip으로 16KB 이하

### Tsuzuri와의 차이

Tsuzuri는 README에서 링크를 따라가며 GitHub Actions로 빌드합니다. tm2d는 `docs/`의 Markdown을 Pages의 표준 빌드로 공개합니다.

사이트는 [여기](https://akilasatolu.github.io/tiny-md2docs/ko/)입니다.
