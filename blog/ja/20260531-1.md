# まだ`for`ループでリストの重複を削除していますか？

私は以前、重複を削除するコードをこう書いていた。

```python
nums = [1, 2, 2, 3, 1]

result = []

for n in nums:
    if n not in result:
        result.append(n)

print(result)
# [1, 2, 3]
```

このコードは動くし理解しやすいが、Pythonにはもっとシンプルに同じ結果を得る方法がある。

## `set`を使う

```python
nums = [1, 2, 2, 3, 1]

print(list(set(nums)))
# [1, 2, 3]
```

```python
text = ["hello", "hello", "world"]

print(list(set(text)))
# ['hello', 'world']
```

この方法はかなり短くきれいだ。

ただし、`set`は重複した値を削除する一方で、元の順序は保持されない。

元の順序を保ちたい場合は、別の方法が必要になる。

## `dict.fromkeys()`で順序を保つ

```python
nums = [1, 2, 2, 3, 1]

print(list(dict.fromkeys(nums)))
# [1, 2, 3]
```

```python
text = ["hello", "hello", "world"]

print(list(dict.fromkeys(text)))
# ['hello', 'world']
```

辞書のキーは一意でなければならないため、この方法でも重複が削除される。

`set`と違い、Python 3.7以降の辞書は挿入順を保持するため、元の順序がそのまま保たれる。

## TypeScript / JavaScriptで重複を削除する

TypeScriptとJavaScriptの`set`は挿入順を保持する。

```ts
const nums = [1, 2, 2, 3, 1];

console.log([...new Set(nums)]);
// [1, 2, 3]
```

```ts
const text = ["hello", "hello", "world"];

console.log([...new Set(text)]);
// ['hello', 'world']
```

## 感想

以前は`for`ループで重複削除のロジックを書いていたが、Pythonの組み込み機能を使えば1行にまで短縮できる。

自分にとって、ちょっとした革命のように感じた。

小さな組み込み機能を学ぶだけで、コードがぐっとシンプルでPythonらしくなることがある。
