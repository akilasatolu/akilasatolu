# Pythonでドット記法を使って定数を管理する方法

Pythonで定数をグループ化したい場合、以下のようなコードを書きたくなるかもしれない。

```python
from constants import CONST as C

print(C.NAME)
```

## 悪い例

```python
# constants.py

NAME = "name"

CONST = (
    NAME
)
```

```python
from constants import CONST as C

print(C.NAME)
```

これは動かない。なぜなら:

```python
CONST = (
    NAME
)
```

は実質的に以下と同じだからだ:

```python
CONST = "name"
```

## `dict`を使う方法

```python
# constants.py

CONST = {
    "NAME": "name",
    "AGE": 20,
}
```

```python
from constants import CONST as C

print(C["NAME"])
```

### 特徴

- JSONのように見える
- 動的に扱いやすい
- `[]`で値にアクセスする

## `SimpleNamespace`を使う方法

`C.NAME`のようにドット記法で値にアクセスしたい場合、`SimpleNamespace`が便利だ。

```python
from types import SimpleNamespace

CONST = SimpleNamespace(
    NAME="name",
    AGE=20,
)
```

```python
from constants import CONST as C

print(C.NAME)
```

### 特徴

- ドット記法で値にアクセスできる
- IDEの補完と相性が良い
- 設定値や定数の管理に向いている

### 注意点

`SimpleNamespace`はミュータブル(変更可能)だ。

```python
CONST.NAME = "new name"
```

これはエラーなく動いてしまう。

### イミュータブルにしたい場合

`@dataclass(frozen=True)`を使うことができる。

```python
from dataclasses import dataclass

@dataclass(frozen=True)
class Const:
    NAME: str = "name"

CONST = Const()
```

```python
CONST.NAME = "new"
```

これは`FrozenInstanceError`を発生させる。

## どれを使うべきか

| 選択肢 |向いている用途|
|---|---|
| `dict` | JSONライクなデータ構造|
| `SimpleNamespace` | 軽量な定数オブジェクト|
| `frozen dataclass` | イミュータブルな定数オブジェクト|
