# Learning WebSocket with a Simple Example

I heard that WebSocket enables real-time updates, so I build a simple sample application to see how it works.

In this article, I'll build a simple application where clicking a button increments a counter and instantly updates the result for all connected users.

## What Is WebSocket?

In a typical HTTP request, the client sends a request, the server returns a response, and the connection is closed.

In contrast, once a WebSocket connection is established, the client and server can communicate with each other over the same connection.

Because of this, WebSocket is commonly used in real-time application s such as:

* Chat applications
* Online games
* Stock price and exchange rate updates
* Notification Syetems
* Collaborative editing tools

## Code Example

### Client(`index.html`)

```html
<!DOCTYPE html>
<html>
<body>

<h1 id="count">0</h1>

<button id="plus">
  +1
</button>

<script>
const ws = new WebSocket("ws://localhost:3000");

const countEl =
  document.getElementById("count");

// Receives a message from server.
ws.onmessage = (event) => {
  countEl.textContent = event.data;
};

// Connection established.
ws.onopen = () => {
  console.log("Connected");
};

// An error occurred.
ws.onerror = (error) => {
  console.error(error);
};

// Connenction closed.
ws.onclose = () => {
  console.log("Closed");
};

// Sends a message to the server when the button is clicked.
document
  .getElementById("plus")
  .addEventListener("click", () => {

    ws.send("increment");

  });
</script>

</body>
</html>
```

### Server(`server.js`)

```javascript
const WebSocket = require("ws");

const wss = new WebSocket.Server({
  port: 3000
});

let count = 0;

wss.on("connection", (ws) => {

  // Sends the current count when a client connects.
  ws.send(count.toString());

  ws.on("message", () => {
    count++;

    // Sends the updated count to all connected clients.
    wss.clients.forEach((client) => {
      client.send(count.toString());
    });
  });

});

console.log("Server Started");
```

## How It Works

1. A browser connects to the WebSocket server.
2. The server sends the current count value.
3. The user clicks the "+1" button.
4. The client sends a mesasge to the server.
5. The server increments the counter.
6. The server sends the updated count value to all connected clients.
7. Each connected browser updates in real time.

## Client-Side Processing

### Connecting to a WebSocket Server

```javascript
const ws = new WebSocket("ws://localhost:3000");
```

`new WebSocket()` establishes a WebSockert connection.

* `ws://` : An unencrypted WebSocket connection
* `wss://` : A WebSocket connection encrypted with SSL/TLS

When your website uses HTTPS, you should use `wss://` for WebSocket connection.

### Connection Established(`onopen`)

```javascript
ws.onopen = () => {
  console.log("Connected");
};
```

This event is triggered when the connection to the WebSocket server is established.

### Receiving Messages(`onmessage`)

```javascript
ws.onmessage = (event) => {
  countEl.textContent = event.data;
};
```

This event is triggered when a message is received from the server.

You can access the received data through `event.data`.

### Connection Error(onerror)

```javascript
ws.onerror = (error) => {
  console.error(error);
};
```

This event is triggered when an error occurs during the WebSocket connection.

### Connection Closed(`onclose`)

```javascript
ws.onclose = () => {
  console.log("Closed");
};
```

This event is triggered when the WebSocket connection is closed.

### Sending Messages(`send`)

```javascript
ws.send("increment");
```

`send()` sends a message to the WebSocket server.

In this example, clicking the button sends the message `"increment"` to the server.

## Server-Side Processing

### Creating a WebSocket Server

```javascript
const wss = new WebSocket.Server({
  port: 3000
});
```

This creates a WebSocket server that listens on port 3000.

### Client Connection

```javascript
wss.on("connection", (ws) => {
```

This event is triggered when a client connects.

A new `ws` object is created for each client connection.

### Receiving Messages

```javascript
ws.on("message", () => {
```

This event is triggered when a message is received from a client.

In this example, the received message is ignored, and the counter is simply incremented.

### Sending Messages

```javascript
ws.send(data);
```

`send()` sends a message to a specific client.

### Broadcasting Messages

```javascript
wss.clients.forEach((client) => {
  client.send(count.toString());
});
```

This sends the same message to all connected clients.

As a result, if the application is open in multiple browser windows, all of them are updated at the same time.

## How WebSocket Differs from HTTP

| Feature | HTTP | WebSocket |
|---------|------|-----------|
| Communication Model | Request/Response | Full-duplex communication |
| Connection | Connection closes after each request | Persistent connection |
| Real-Time Capability | Low | High |
| Server-Initiated Messages | Not supported | Supported |
| Typical Use Cases | General web applications | Chat, notifications, online games |

## Conclusion

Web Socket enables full-duplex communication over a persistent connection between a client and a server.

In this example, we walked through the following flow:

* The client sends a message to the server.
* The server increments  the counter.
* The server broadcasts the updated count to all connected clients.
* All connected clients are updated in real time.

This communication model is especially useful for building applications such as chat systems and real-time notifications.
