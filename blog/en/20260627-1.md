This is a memo on learning the basics of Ruby.

## String

### String Interpolation
```ruby
puts "Hello #{family_name} #{first_name}"
```
String interpolation is available when using double quotes(`""`).

```ruby
puts 'Hello #{family_name} #{first_name}'
```
String interpolation is not available when using single quotes(`''`).

### Type Checking

```ruby
puts hello.class
```
In JavaScript, you can check a value's type using `typeof`. In Ruby, however, all values are objects, so you can check their classes using the `class` method.

The syntax for calling methods on objects is similar to JavaScript. However, Ruby is a class-based language, whereas JavaScript is prototype-based.

## Array

### Adding Elements

```ruby
fruits << "grape"
```
Add an element to an array using `<<`.

#### Output

```ruby
puts fruits
p fruits
```
I'm still getting used to the differences between `puts` and `p`.

- `puts`：Displays output in a human-readable format.
- `p`：Displays the object's internal representation. Useful for debugging.

## Hash

Ruby's`Hash` is similar to JavaScript's`Object`.

```ruby
user = {
  name: "Taro",
  age: 20
}
```
Symbols are often used as keys in a Hash.

```ruby
:name
:age
```

## Boolean

In Ruby, Only the following two values are falsy:
```ruby
false
nil
```
All other values are truthy.

## Conditional Statements

### if
```ruby
age = 15
if age >= 20
  puts "adult"
elsif age >= 10
  puts "child"
else
  puts "baby"
end
```

### unless
```ruby
unless value
  puts "empty"
end
```
This is equivalent to the following code:
```ruby
if !value
  puts "empty"
end
```

### case

This is similar to the `switch` statement in other programming languages.
```ruby
case role
when "admin"
  puts "Admin"
when "user"
  puts "User"
end
```

### Ternary operator
```ruby
puts age >= 20 ? "adult" : age >= 10 ? "child" : "baby"
```

Although you can write it in a single line, using a regular `if` statement is usuall.

### Postfix `if`

```ruby
puts "adult" if age >= 20
```

A postfix `if` is easy to read when there is only one condition.

## Iteration

### each
```ruby
users = ["Taro", "Hanako", "Jiro"]
users.each do |user|
  puts user
end
```
This works similarly to a `for` loop in other programming languages.

### map

```ruby
users = ["taro", "hanako", "jiro"]
result = users.map do |user|
  user.upcase
end
p users
p result
```

#### Result

```ruby
["taro", "hanako", "jiro"]
["TARO", "HANAKO", "JIRO"]
```
`map` returns a new array and leaves the original array unchanged.

### select

```ruby
ages = [10, 20, 30, 40]
result = ages.select do |age|
  age >= 20
end
p result
```

#### Result

```ruby
[20, 30, 40]
```

`select` returns only the elements that match the condition.

### reject

```ruby
result = ages.reject do |age|
  age < 20
end
p result
```

#### Result

```ruby
[20, 30, 40]
```

`reject` returns a new array excluding the elements that match the condition.

---

You can use these methods much like to `map()` and `filter()` in JavaScript.

## Methods

### Return Values
```ruby
def greet(name)
  "Hello #{name}"
end
puts greet("Taro")
```
In Ruby, the last evaluated value is returned automatically.

Use the `return` statement when you want to exit a method early.

### Keyword Argument

```ruby
def create_user(name:, age:)
  "#{name} #{age}"
end
puts create_user(name: "Taro", age: 20)
```

#### Benefits

- The purpose of each argunent is easier to understand.
- You don't need to worry about the order of the arguments.

## Class

```ruby
class User
  attr_accessor :name
  def initialize(name)
    @name = name
  end
  def greet
    "Hello #{@name}"
  end
end
user = User.new("Taro")
puts user.name
puts user.greet
user.name = "Hanako"
puts user.greet
```

### attr_accessor

```ruby
attr_accessor :name
```

`attr_accessor` automatically generates getter and setter methods.

### attr_reader

```ruby
attr_reader :name
```

`attr_reader` creates a read-only accessor.

### attr_writer

```ruby
attr_writer :name
```

`attr_writer` creates a write-only accessor.
