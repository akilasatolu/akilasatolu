# How to Manage Constants using Dot Notation in Python.

If you want to group constants in Python, you may want to write code like this:

```python
from constants import CONST as C

print(C.NAME)
```

## Bad Example

```python
# constants.py

NAME = "name"

CONST = (
    NAME
)
```

```python
from constants import CONST as C

print(C.NAME)
```

This does not work because:

```python
CONST = (
    NAME
)
```

is effectively equivalent to:

```python
CONST = "name"
```

## How to Use a `dict`

```python
# constants.py

CONST = {
    "NAME": "name",
    "AGE": 20,
}
```

```python
from constants import CONST as C

print(C["NAME"])
```

### Features

- It looks like JSON.
- Easy to use dynamically.
- Access values using `[]`.

## How to Use `SimpleNamespace`

`SimpleNamespace` is useful when you want to access values using dot notation like `C.NAME`.

```python
from types import SimpleNamespace

CONST = SimpleNamespace(
    NAME="name",
    AGE=20,
)
```

```python
from constants import CONST as C

print(C.NAME)
```

### Features

- You can access values using dot notation.
- Works well with IDE autocompletion.
- Suitable for config and constant management.

### Caution

`SimpleNamespace` is mutable.

```python
CONST.NAME = "new name"
```

This works without errors.

### If You Want it to Be Immutable.

You can use `@dataclass(frozen=True)`.

```python
from dataclasses import dataclass

@dataclass(frozen=True)
class Const:
    NAME: str = "name"

CONST = Const()
```

```python
CONST.NAME = "new"
```

This will raise a `FrozenInstanceError`.

## When to Use Each Option

| Option |Best For|
|---|---|
| `dict` | JSON-like Data structures|
| `SimpleNamespace` | Lightweight Constant objects|
| `frozen dataclass` | Immutable Constants objects|
