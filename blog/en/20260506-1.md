# What is Machine Learning?

Machine Learning is a technology that learns patterns and rules from data to make prediction, classification and analyses.

## Types of Learning

### Supervised Learning

Machine learning using labeled data.
It learns the relationship between input data and correct answers, then makes predictions for new data.

#### Regression

Predicting numerical values.

Examples:

- Sales forecasting
- Temperature prediction
- Stock price prediction 

#### Classification

Predicting categories.

Examples:

- Spam detection
- Disease classification
- Image recognition

---

### Unsupervised Learning

Machine learning that learns data structures without labeled data.
It is used to discover patterns, relationships and features within data.

#### Clustering

Grouping similar data togather.

Examples:

- Customer segmentation
- Product categorization

#### Dimensionality Reduction

Reducing the number of features to make data easier to handle.

Examples:

- Data visualization
- Noise reduction
