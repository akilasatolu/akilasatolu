# Data Analysis・Visualization

In data analysis, visualizing data as charts makes it easier to understand trends and patterns than simply looking at raw numerical values.

With pandas, you can easily create charts using DataFrame.plot().

## Chart

### Bar Chart

A bar chart is used to compare values across different categories.

It is often used for comparing sales, population sizes and rankings.

```python
df.plot(kind='bar')
```

### Scatter Plot

A scatter plot is used to examine the relationship between numerical values.

It is useful for analyzing correlations.

```python
df.plot(kind='scatter', x='raw', y='raw')
```

### Line Chart

A line chart is commonly used to examine changes and trends over time.

It works well with time-series data.

```python
df.plot(kind='line')
```

### Histogram

A histogram is used to examine how data is distributed across different ranges.

It is useful for understanding data bias and variation.

```python
df.plot(kind='hist')
```

### Box Plot

A box plot is used to examine the midian, variation, and outliers in data.

It is commonly used in statistical analysis.

```python
df.plot(kind='box')
```

## Display Charts

Charts are usually displayed using matplotlib.pyplot.show().

```python
import matplotlib.pyplot as plt
plt.show()
```
