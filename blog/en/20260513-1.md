# Oh, I messed up my Git tag

I added a Git tag, then checked the tag message on GitHub and realized that I had written the wrong message.

In that situation, I can simply recreate the tag.

Normally, creating a tag with the same name causes an error, but I can overwrite it with the `-f` option.

Don't forget to use `-f` when pushing the tag as well.
