# Do you still use a `for` roop to remove duplicates from a list?

I've written code to remove duplicates like this:

```python
nums = [1, 2, 2, 3, 1]

result = []

for n in nums:
    if n not in result:
        result.append(n)

print(result)
# [1, 2, 3]
```

This code works and id easy to understand, but Python provides a much simpler way to achieve the same result.

## Using `set`

```python
nums = [1, 2, 2, 3, 1]

print(list(set(nums)))
# [1, 2, 3]
```

```python
text = ["hello", "hello", "world"]

print(list(set(text)))
# ['hello', 'world']
```

This approach is much shorter and cleaner.

However, while `set` remove duplicate values, it does not preserve their original order.

If you need to maintain the original order, you'll need to use a different approach.

## Using `dict.fromkeys()` to Preserve Order

```python
nums = [1, 2, 2, 3, 1]

print(list(dict.fromkeys(nums)))
# [1, 2, 3]
```

```python
text = ["hello", "hello", "world"]

print(list(dict.fromkeys(text)))
# ['hello', 'world']
```

This approach also removes duplicates because dictionary keys must be unique.

Unlike `set`, dictionaries preserve insertion order starting from Python 3.7, so the original order is kept intact.

## Removing Duplicates in TypeScript / JavaScript

`set` in TypeScript and JavaScript preserves insertion order.

```ts
const nums = [1, 2, 2, 3, 1];

console.log([...new Set(nums)]);
// [1, 2, 3]
```

```ts
const text = ["hello", "hello", "world"];

console.log([...new Set(text)]);
// ['hello', 'world']
```

## My Thoughts

I used to write duplicate-removal logic with a `for` loop, but Python's built-in features can reduce it to a single line of code.

It felt like a small revolution to me.

Sometimes, learning a small built-in feature can make your code much simpler and more Pythonic.
