# React `useState`에서 `prev`로 상태 업데이트하기

React의 `useState`에서는 다음 state가 현재 state에 의존할 때 `prev`를 사용해야 한다.

## `prev`가 필요한 이유

``` ts
setCount(count + 1);
setCount(count + 1);
// 0 + 1
// 0 + 1
```

두 업데이트가 같은 `count`를 참조하기 때문에 결과는 `1`이 된다.

하지만 `prev`를 사용하면 각 업데이트가 최신 state 값을 받기 때문에 순서대로 적용된다.

```ts
setCount(prev => prev + 1);
setCount(prev => prev + 1);
// 0 → 1 → 2
```

이는 React가 state를 즉시 업데이트하지 않기 때문이다.
대신 state 업데이트는 큐에 쌓였다가 다음 렌더링 때 처리된다.

따라서 다음 state가 현재 state에 의존할 때는 `prev`를 사용하는 것이 가장 안전하다.

## 단일 값 업데이트하기(예: `boolean`)

현재 값이 토글된다.

```ts
const [isOpen, setIsOpen] = useState(false);
setIsOpen(prev => !prev);
// false → true
// true → false
```

## 배열 state 업데이트하기

지정한 `index`의 값만 토글된다.

```ts
const [arrStates, setArrStates] = useState<boolean[]>(
  [false, false, false]
);
const updatedAA = (index: number) => {
  setArrStates(prev =>
    prev.map((v, i) =>
      i === index ? !v : v
    )
  );
};
```

## 느낀 점

다음 `state`가 현재 `state`에 의존한다면 `prev`를 사용해야 한다.

다음과 같은 코드는:

```ts
setCount(count + 1);
```

연속적인 업데이트에서 의도하지 않은 값을 만들어 버그를 일으킬 수 있다.
또한 `prev`는 단순한 매개변수 이름이므로 원하는 이름으로 바꿔도 상관없다.

`prev`가 왜 존재하는지 이해하면서 React가 state 업데이트를 어떻게 처리하는지 더 잘 이해하게 되었다.
