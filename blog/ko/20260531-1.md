# 아직도 `for` 루프로 리스트 중복을 제거하고 있나요?

나는 예전에 중복을 제거하는 코드를 이렇게 작성했다.

```python
nums = [1, 2, 2, 3, 1]

result = []

for n in nums:
    if n not in result:
        result.append(n)

print(result)
# [1, 2, 3]
```

이 코드는 동작하고 이해하기도 쉽지만, Python에는 같은 결과를 훨씬 더 간단하게 얻는 방법이 있다.

## `set` 사용하기

```python
nums = [1, 2, 2, 3, 1]

print(list(set(nums)))
# [1, 2, 3]
```

```python
text = ["hello", "hello", "world"]

print(list(set(text)))
# ['hello', 'world']
```

이 방법은 훨씬 짧고 깔끔하다.

하지만 `set`은 중복된 값을 제거하는 대신 원래 순서를 유지하지 않는다.

원래 순서를 유지해야 한다면 다른 방법이 필요하다.

## `dict.fromkeys()`로 순서 유지하기

```python
nums = [1, 2, 2, 3, 1]

print(list(dict.fromkeys(nums)))
# [1, 2, 3]
```

```python
text = ["hello", "hello", "world"]

print(list(dict.fromkeys(text)))
# ['hello', 'world']
```

딕셔너리의 키는 고유해야 하므로 이 방법으로도 중복이 제거된다.

`set`과 달리 Python 3.7부터 딕셔너리는 삽입 순서를 유지하므로 원래 순서가 그대로 보존된다.

## TypeScript / JavaScript에서 중복 제거하기

TypeScript와 JavaScript의 `set`은 삽입 순서를 유지한다.

```ts
const nums = [1, 2, 2, 3, 1];

console.log([...new Set(nums)]);
// [1, 2, 3]
```

```ts
const text = ["hello", "hello", "world"];

console.log([...new Set(text)]);
// ['hello', 'world']
```

## 느낀 점

예전에는 `for` 루프로 중복 제거 로직을 작성했지만, Python의 내장 기능을 사용하면 단 한 줄로 줄일 수 있다.

나에게는 작은 혁명처럼 느껴졌다.

작은 내장 기능 하나를 배우는 것만으로도 코드가 훨씬 간결하고 Python다워질 수 있다.
