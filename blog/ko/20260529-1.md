# Python에서 점(dot) 표기법으로 상수를 관리하는 방법

Python에서 상수를 그룹화하고 싶다면 다음과 같은 코드를 작성하고 싶을 수 있다.

```python
from constants import CONST as C

print(C.NAME)
```

## 잘못된 예시

```python
# constants.py

NAME = "name"

CONST = (
    NAME
)
```

```python
from constants import CONST as C

print(C.NAME)
```

이 코드는 동작하지 않는다. 왜냐하면:

```python
CONST = (
    NAME
)
```

이 코드는 사실상 다음과 동일하기 때문이다:

```python
CONST = "name"
```

## `dict` 사용하기

```python
# constants.py

CONST = {
    "NAME": "name",
    "AGE": 20,
}
```

```python
from constants import CONST as C

print(C["NAME"])
```

### 특징

- JSON처럼 보인다
- 동적으로 사용하기 쉽다
- `[]`를 사용해 값에 접근한다

## `SimpleNamespace` 사용하기

`C.NAME`처럼 점 표기법으로 값에 접근하고 싶다면 `SimpleNamespace`가 유용하다.

```python
from types import SimpleNamespace

CONST = SimpleNamespace(
    NAME="name",
    AGE=20,
)
```

```python
from constants import CONST as C

print(C.NAME)
```

### 특징

- 점 표기법으로 값에 접근할 수 있다
- IDE 자동완성과 잘 맞는다
- 설정 및 상수 관리에 적합하다

### 주의사항

`SimpleNamespace`는 변경 가능(mutable)하다.

```python
CONST.NAME = "new name"
```

이 코드는 오류 없이 동작한다.

### 불변(immutable)으로 만들고 싶다면

`@dataclass(frozen=True)`를 사용할 수 있다.

```python
from dataclasses import dataclass

@dataclass(frozen=True)
class Const:
    NAME: str = "name"

CONST = Const()
```

```python
CONST.NAME = "new"
```

이 코드는 `FrozenInstanceError`를 발생시킨다.

## 상황별 선택 기준

| 옵션 |적합한 경우|
|---|---|
| `dict` | JSON과 유사한 데이터 구조|
| `SimpleNamespace` | 가벼운 상수 객체|
| `frozen dataclass` | 불변 상수 객체|
